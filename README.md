# Countdown Timer

## Description
A Python countdown timer that takes a time from the user and counts down in the terminal.

## Features
- Accepts time in hours:minutes:seconds format.
- Checks whether the input is valid.
- Displays the countdown one second at a time.
- Prints a message when the timer finishes.

## Requirements
- Python 3
- No external libraries required.

## How to Run
Open the terminal in this folder and run:

python main.py
